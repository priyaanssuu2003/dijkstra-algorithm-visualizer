Pseudocode


Dijkstra(G, source):
    for each vertex v:
        distance[v] = infinity
        previous[v] = NULL

    distance[source] = 0

    while there are unvisited vertices:
        u = vertex with minimum distance
        mark u as visited

        for each neighbor v of u:
            newDistance = distance[u] + weight(u, v)
            if newDistance < distance[v]:
                distance[v] = newDistance
                previous[v] = u

    return distance, previous

How Dijkstra's Algorithm Works

Step 1 — Initialization

Set the source distance to 0 and all other node distances to infinity (∞).

Step 2 — Select Minimum

Select the unvisited vertex with the smallest tentative distance.

Step 3 — Relax Edges

Check all neighboring vertices. Calculate the distance to each neighbor through the current node. If this new distance is smaller than the known distance, update it (relax the edge).

Step 4 — Mark Visited

Mark the current vertex as permanently processed (visited). It won't be checked again.

Step 5 — Repeat

Repeat steps 2-4 until all reachable vertices are visited or the destination is reached.

Algorithm Complexity

Time Complexity

O(V²) using a simple array/matrix implementation.

O((V + E) log V) using a priority queue (min-heap).

V = number of vertices, E = number of edges

Space Complexity

O(V + E)

Required to store the graph (Adjacency List), distances array, and priority queue/visited set.

About Dijkstra

The algorithm was conceived by Dutch computer scientist Edsger W. Dijkstra in 1956 and published three years later.

It is one of the most famous algorithms in computer science, used in network routing protocols (like IS-IS and OSPF) and as a fundamental concept in graph theory and the Design and Analysis of Algorithms (DAA).
